# Form: Prompt or workflow description

Material Facts: four knowledge infographics where each chart is built from the material it measures (copper ingots, coffee beans, raw cotton, lithium metal). Every pixel and glyph was generated by Hy Image 3.5 preview on GMI Cloud at native 2048x2048, with nothing overlaid in code.

Workflow: my agent Plate (built on Vercel's eve) has Muse Spark 1.3 turn verified USGS and USDA data into a typed design spec, and code compiles it into a Hy prompt that quotes every string to print. After each render, Muse Spark reads the image back blind and code diffs it against the spec; mistakes are fixed with reference-guided Hy edits of the best draft, up to six passes. Today it caught a total printed as 28,000 instead of 23,000, "Summaties" for "Summaries" four times, an invented axis, and invented callouts. I proofread every final at full size.
